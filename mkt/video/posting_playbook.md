# Posting playbook — 25 languages (2026-09-29 UTC)

Assets: 21s vertical 1080×1920, 30fps master + 12fps cut (`mkt/video/`).
Copy: `post_texts_25langs.txt` (title + description + first comment per lang).
Standing: owner posts manually, cost 0, nothing auto-posted.

## Universal rules (all platforms, all countries)

1. **Native upload per app, never cross-post a downloaded file.** Watermarks =
   40–60% reach cut (IG), demotion (YT), block (VK).
2. **Never same-file + same-caption + same-minute** across platforms — stagger
   12–24h, tweak hook words/tags per platform.
3. **Music**: baked-in CC-BY bed = "Original Sound". Keep license proof +
   credit line (`Music: Night Drive — 1000 Handz (1000Handz.com), CC-BY`) in
   every caption/description. Brand/business accounts: commercial libraries
   only for in-app sounds; never carry one platform's licensed track to another.
4. **Account type**: TikTok = Personal/Creator public (NOT Business — kills
   sounds + reach). IG = Professional Creator. YT = proper country + language.
5. **Country signals**: local SIM (or no foreign SIM), clean local IP (no
   consumer VPN), device language/timezone = target, post in local peak hours.
6. **Every post**: location tag (city), 3–5 tags max (2026 rule — 30-tag dumps
   = spam), keyword spoken aloud in first 3s + burned on screen + first caption
   line, duet/stitch/remix ON, comments ON, pin own CTA comment.
7. **First 60–90 min decide distribution**: post 30–45 min before peak, stay
   online, reply to first comments.
8. **Verify**: check Top countries/cities in analytics after 5–7 posts; if
   wrong, fix signals (SIM/IP/language/location), not content.
