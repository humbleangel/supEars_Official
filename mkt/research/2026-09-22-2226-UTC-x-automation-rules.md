# X automation rules — what got others banned, and our policy

> Filed 2026-09-22 22:26 UTC per owner order. Owner hypothesis: the blocked builder automated posts. I read X's official Automation Rules (Apr 2026), Developer Policy, Developer Guidelines, plus 2026 API pricing/limits reporting. INTERNAL — platform rules, no public post.

## What X bans (official rules)

1. **Non-API automation = permanent suspension.** Scripting the website, browser bots, scrapers, unofficial endpoints — the #1 solo-dev killer. A hand-rolled "auto-post my releases" script on the website (not the API) is a bannable offense by itself.
2. **Spam shapes:** duplicative or substantially similar posts on one account or across accounts; auto-posting about trending topics; unsolicited @mentions or DMs; bulk/aggressive follow, like, repost.
3. **Unlabeled bots.** API bot accounts must carry the automated label, state it in the bio, and link a human-managed account.
4. **API writes cost money now.** No free tier for new developers (pay-per-use since Feb 2026; ~$0.01–0.015 per post, ~$0.20 for posts with URLs). Follow/like/quote-post writes were removed from self-serve tiers entirely (Apr 2026).
5. **Account caps (May 2026):** unverified accounts = 50 original posts + 200 replies/day, API + manual combined. April 2026 bot purge ran at 208 suspensions/minute.

## Our policy (cost 0, ban-proof)

- **Post by hand, in the browser, like a human.** No scripts, no schedulers touching X except through official paid API (which we will not buy — cost 0).
- **No duplicate content** across our accounts; every rail gets its own wording.
- **No trend-hijacking, no auto-replies, no bulk follow/unfollow, no DMs** to strangers. Ever.
- **Volume is naturally safe:** a few hand posts/day sits far under the 50/day cap.
- **Third-party crossposters are guilty until proven innocent:** any tool that automates X must use the official API or it stays off our accounts.
- Same caution travels: Telegram/WhatsApp/IG/TikTok all ban scripted spam — hand-posting everywhere until a platform offers an official free path.
